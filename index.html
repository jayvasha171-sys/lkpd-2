C. Aktivitas 1 — Eksperimen 10 + 20

let a = "10";
let b = "20";
console.log(a + b);

Apa output program?
Outputnya adalah "1020"

Mengapa hasil tersebut terjadi?
Karena a dan b bertipe String (ada tanda petik). Di JavaScript, tanda + untuk String artinya penggabungan / concatenation, bukan penjumlahan. Jadi "10" + "20" = "1020".

Apakah a dan b bertipe Number?
Tidak. Keduanya bertipe String, bukan Number.

Uji sekarang. Apakah prediksimu benar? Jelaskan.
Ya, benar. Setelah dijalankan hasilnya 1020, bukan 30. Ini membuktikan kalau String + String akan digabung, bukan ditambah.

Temuan: Apa perbedaan String dan Number?
String adalah teks / karakter yang ditulis di dalam tanda petik, contoh: "Asep", "10". Tidak bisa dihitung, kalau ditambah akan digabung. Number adalah angka tanpa tanda petik, contoh: 16, 10, 20. Bisa dihitung dengan operasi matematika (+, -, *, /).

E. Aktivitas 3 — Konversi String Menjadi Number

Perbaiki program agar menghasilkan 30. Gunakan Number():

let a = "10";
let b = "20";
let hasil = Number(a) + Number(b);
console.log(hasil); // 30
Catat hasil program: 30
Karena "10" diubah jadi angka 10, dan "20" diubah jadi angka 20. Jadi 10 + 20 = 30.

F. Aktivitas 4 — Program Kasir Sederhana

let harga = Number(prompt("Masukkan harga: "));
let jumlah = Number(prompt("Masukkan jumlah: "));
let total = harga * jumlah;
console.log("Total belanja = " + total);
Jawaban isian: let total = harga * jumlah;
Input Uji Contoh: Harga Rp 5.000, Jumlah 3, Total seharusnya Rp 15.000, Total program Rp 15.000 — Sama / Benar
Tanpa Number(), prompt() akan menghasilkan String, jadi perkalian bisa salah atau penjumlahan jadi penggabungan.

G. Tantangan — Program Hitung Nilai TANTANGAN

let tugas = Number(prompt("Masukkan nilai tugas: "));
let uts = Number(prompt("Masukkan nilai UTS: "));
let uas = Number(prompt("Masukkan nilai UAS: "));
let rataRata = (tugas + uts + uas) / 3;
console.log("Rata-rata = " + rataRata);
Algoritma saya:
1. Minta input nilai tugas lewat prompt(), lalu ubah ke Number.
2. Minta input nilai UTS lewat prompt(), lalu ubah ke Number.
3. Minta input nilai UAS lewat prompt(), lalu ubah ke Number.
4. Hitung rata-rata dengan rumus (tugas + UTS + UAS) / 3, lalu tampilkan hasilnya.

Contoh: Tugas 80, UTS 90, UAS 70 → (80 + 90 + 70) / 3 = 240 / 3 = 80

H. Think — Pair — Share

Mengapa prompt() perlu dikonversi jika hasilnya ingin dihitung?
Karena prompt() selalu menghasilkan String, meskipun yang diketik angka. Kalau tidak dikonversi, hasil perhitungan jadi salah, misal "10" + "20" jadi "1020" bukan 30.

Apa perbedaan "10" dengan 10?
"10" adalah String (teks, pakai tanda petik, tidak bisa dihitung). 10 adalah Number (angka, tanpa tanda petik, bisa dihitung).

Apa yang terjadi jika lupa Number()?
Perhitungan jadi salah. Penjumlahan berubah jadi penggabungan teks, dan total bisa jadi tidak sesuai.

Pair: Setelah dibandingkan dengan teman, jawabannya sama intinya, hanya beda cara menjelaskan. Bisa berbeda karena setiap orang punya contoh dan bahasa yang berbeda.

Share: Satu temuan penting: Selalu gunakan Number() setelah prompt() kalau mau menghitung.
